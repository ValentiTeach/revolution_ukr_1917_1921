# Візуальний стиль «Вільної Долі»

Гра виглядає як 16-бітна пригода зі шкільного комп'ютерного класу: піксельні картини доби, квадратні рамки, ступінчастий рух і синьо-жовті акценти. Цей документ описує правила, щоб кожен новий екран виглядав так само.

## Головні принципи

1. **Жодного вектора там, де можна піксель.** Іконки намальовано бітовими картами, емодзі перетворено на спрайти, заокруглень немає.
2. **Рух кадрами, а не плавно.** Будь-яка анімація ступінчаста, як у спрайтів старих консолей.
3. **Обмежена палітра.** Темний «нічний» фон, бурштин для дій, синій і жовтий для українських акцентів, червоний вишиванки для орнаменту.
4. **Читабельність для дитини.** Основний текст має від 16 до 20 пікселів. Важливі кнопки великі, з чітким натисканням.

## Типографіка

| Роль | Шрифт | Де |
| --- | --- | --- |
| Основний текст, кнопки, заголовки | Pixelify Sans | Уся гра. Має кирилицю, зокрема і, ї, є, ґ |
| Логотип і дрібні «системні» написи | Press Start 2P | Назва гри, «ДВЕРІ 001», «ЗВАННЯ», таймери |
| Щоденник героя | Caveat | Лише пергамент щоденника: це «рукописна» сторінка, свідомий виняток |

Згладжування шрифтів вимкнено (`-webkit-font-smoothing: none`), щоб літери лишалися різкими.

## Елементи

### Піксельна рамка `.pixel-frame`
Це 9-зрізна рамка з `border-image`: темний контур, світлий скіс угорі ліворуч, бурштин і темна тінь унизу праворуч. Кути «зрізані» на один піксель. Варіанти: `.pixel-frame-violet` для доручень і `.pixel-frame-sky` для інформаційних вікон. Використовується для сцени, вікон і великих панелей.

### Кнопка `.pixel-btn`
- Кути зрізано через `clip-path` на 3 пікселі.
- Об'єм зроблено внутрішніми тінями: світлий верх-ліво, темний низ-право.
- Наведення піднімає кнопку на 2 пікселі. Натискання опускає її й інвертує скіс, тож вона «вдавлюється».
- Рамку фокусу показано всередині кнопки, щоб її не обрізали кути.

### Сегментована смужка `.px-bar`
Смужка здоров'я з «щілинами» кожні 8 пікселів. Заливка росте кроками, `steps(6)`. Так показано метрики, фракції, прогрес звання, хованки й наслідки рішень.

### Зрізані кути `.px-notch`
Для невеликих плашок: імені співрозмовника, карток переваг, підписів.

### Піксельні іконки
Файл `src/components/icons.tsx` містить 46 іконок 12×12. Кожна задана рядками:
`#` — основний колір, `+` — тінь з прозорістю 45%, `.` — порожньо. Назви збігаються з lucide-react, тож нова іконка додається одним масивом рядків.

### Піксельні спрайти з емодзі
`<PixelEmoji emoji="🚪" size={48} />` малює емодзі на полотні 16×16. Далі він прибирає напівпрозорі краї, зменшує палітру, обводить темним контуром і збільшує без згладжування. Він потрібен скрізь, де емодзі великий: знахідки, медалі, двері, серця, шухляди, міні-ігри, сповіщення. Дрібні емодзі всередині речень можна лишати текстом.

### Аватари
`PixelAvatar` малює портрети 32×32 прямокутниками з `shapeRendering="crispEdges"`. Кожен новий персонаж отримує окремий портрет, і тест перевіряє, що портрет існує.

## Рух

Усі переходи бібліотеки motion за замовчуванням ступінчасті. `MotionConfig` в `App.tsx` задає `pxEase(4)`, а сам `pxEase` лежить у `src/game/motion.ts`. CSS-анімації завжди мають `steps()`.

| Анімація | Клас | Де |
| --- | --- | --- |
| Дихання персонажа | `.px-bob` | Співрозмовник, герой, предмети в торбі |
| Махання крилами | `.animate-flap` | Сизокрил |
| Миготіння | `.px-blink` | Курсор друку, «НАТИСНИ, ЩОБ ПОЧАТИ», тривога патруля |
| Курсор вибору | `.px-cursor` | Стрілка ▶ біля варіанта під мишкою, ▼ після тексту |
| Поява «пуф» | `.px-pop` | Нова зірка, знахідка, пройдені двері |
| Спливання «+N» | `.px-rise` | Нові зірки біля лічильника |
| Розгортання вікна | `.px-open`, `scaleY` у `Modal` | Діалогова панель, вікна |
| Розсипання екрана | `PixelWipe` | Перехід між вкладками й актами |
| Проявлення сцени | `clip-path` кроками | Зміна фонової картини |
| Панорама | `.px-pan` | Повільний рух камери по картині |
| Сніг і пил | `.px-snow`, `.px-dust` | Крути, площа, зала Ради |
| Мерехтіння люстри | `.px-flicker` | Зала Центральної Ради |
| Хмари й голуб | `.px-cloud`, `.px-fly` | Титульний екран |
| Падіння літер | `.px-drop` | Логотип |
| Відчинення дверей | `.px-door-open` | Пройдені двері доручення |
| Тремтіння | `.animate-shake` | Помилка, втрата серця |

Якщо в системі ввімкнено «зменшити рух» (`prefers-reduced-motion`), усі ці анімації вимикаються, а екранний перехід не показується.

## Атмосфера сцен

- **Площа (hero):** пил у повітрі, панорама.
- **Зала Ради (rada):** тепле мерехтіння люстри, пил.
- **Крути (kruty):** два шари квадратного снігу різної швидкості.
- **Карта (map):** тільки панорама, щоб не заважати читати.

Поверх усіх сцен лежить ефект старого монітора `.px-crt`: рядки розгортки й віньєтка.

## Як додати новий екран

1. Обгорни головну панель у `pixel-frame` або `px-notch` з `border-2`.
2. Кнопки дій роби з `pixel-btn`: бурштиновий фон для головної дії, кам'яний для другорядної.
3. Іконки бери з `icons.tsx`, великі емодзі показуй через `PixelEmoji`.
4. Смужки прогресу роби з `px-bar`.
5. Для руху використовуй готові класи або `pxEase(n)`. Плавних `ease-in-out` і пружин не використовуй.
