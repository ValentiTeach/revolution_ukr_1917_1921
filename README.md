# Вільна Доля: 1917–1921

Піксельна пригода для дітей про Українську революцію 1917–1921 років.

## Лор

Гравець — **юний джура** (посильний) Української Центральної Ради. Весною 1917 року він або вона потрапляє до Педагогічного музею в Києві й разом із **поштовим голубом Сизокрилом** проходить шістнадцять актів революції: від створення Ради й Акту Злуки до двох Зимових походів, Сивашу, Ризького миру та трагедії під Базаром 1921 року.

### Акти

| № | Акт | Період |
| --- | --- | --- |
| I–VIII | Центральна Рада, Універсали, Крути, Гетьманат, Акт Злуки | 1917 — січень 1919 |
| IX | **Республіки-маски** — «радянські уряди», створені Москвою (Харків, Донецько-Криворізька, Одеська, Таврійська, Курськ) | грудень 1918 — лютий 1919 |
| X | **Отаманщина** — Холодноярська й Медвинська республіки, Гуляйполе, Григоріїв, боротьба з погромами | весна — літо 1919 |
| XI | **Серпень 1919** — два прапори над Києвом, наступ Денікіна і його провал через рейд Махна (Перегонівка, Бердянськ, Таганрог) | серпень — жовтень 1919 |
| XII | **Трикутник смерті** — Камʼянець, тиф, перемирʼя УГА з білими | листопад 1919 |
| XIII | **Перший Зимовий похід** — Омелянович-Павленко, Тютюнник, Холодний Яр, «Залізний хрест» | 6.12.1919 — 6.05.1920 |
| XIV | **1920** — Варшавський договір, Київ, оборона Замостя | квітень — листопад 1920 |
| XV | **Крим 1920** — Старобільська угода махновців і більшовиків, Сиваш, евакуація білих, зрада махновців | жовтень — листопад 1920 |
| XVI | **1921 — загибель держави** — Ризький мир, табори інтернованих, Другий Зимовий похід, Базар | березень — грудень 1921 |

Кожен новий акт має свою піксельну сцену, 2–3 розмови з історичними постатями (Чехівський, Чучупак, Махно, Кравс, Омелянович-Павленко, Тютюнник, Безручко, Каретник), підказки Сизокрила, щоденник, вікторину, доручення й міні-гру привалу. Якщо пройти всю гру «як було», фінал буде історичним; альтернативні фінали відкриваються лише тоді, коли гравець справді змінював хід подій.

- **Сизокрил** пояснює кожну сцену простими словами (кнопка «Що це?» біля голуба).
- Після кожного акту джура пише сторінку **щоденника**. Разом записи складають особисту історію героя, яка закінчується епілогом «багато років потому».
- Поради джури змінюють хід подій. Позначка «📜 Як було» показує справжній історичний вибір, «⚡ А якби?» відкриває альтернативну гілку.

## Варіанти відповідей

У кожній розмові є від трьох до чотирьох варіантів:

- **📜 Як було** — справжній історичний вибір.
- **⚡ А якби?** — альтернативна гілка.
- **🤝 Компроміс** та **🔥 Сміливо** — спроба знайти середину або нестандартний хід.
- **🔓 Таємний** — відкривається лише після доручення, знахідки або коли фракція тобі довіряє.

Перед рішенням можна **розпитати** співрозмовника: у кожній сцені є два питання з відповідями простими словами.

## Доручення (у дусі DOORS і Forsaken)

Кожен акт має головне доручення — коридор із 3–4 «дверей». За кожними дверима чекає коротка міні-гра:

| Міні-гра | Що робити |
| --- | --- |
| Полагодь дроти | Протягни дроти пальцем до клем того ж кольору й знака (є знаки для дальтоніків) |
| Влуч у зону | Кругова шкала: тисни, коли стрілка в зеленому секторі, золото — «ідеально ×2» |
| Сховайся! | Працюй і ховайся від патруля. Подих у схованці закінчується, шум кличе патруль, бувають хибні тривоги |
| Знайди річ | Шухляди з підказками «гаряче / холодно», ліхтарик і шухляди, що заїдають |
| Кодовий замок | Барабани сейфа, записка з підказками, кольори підказують цифри |
| Азбука Морзе | Справжній телеграфний ключ: коротке натискання — крапка, довге — тире |
| Розклади по місцях | Перетягни картку в скриньку й дізнайся, чому саме туди |
| Телеграма | Набірні бруски з зайвими словами-пастками |
| Памʼять | На початку картки відкриваються на мить — запамʼятовуй! |
| Затримай ешелон | Відкручуй гайки на стиках рейок, поки не доїхав потяг |
| **Тачанка** | Степовий рейд: перемикай колії, оминай ями, копиці й дріт (є нічний режим) |
| **Брід** | Промацуй дно Сивашу або лід жердиною, поки вітер не змінився |
| **Пароплави** | Розсади біженців так, щоб кожен корабель був повний (задача на додавання) |
| **Маршрут походу** | Покрокова мапа з туманом війни: харчі, тепло, села, гарнізони, розвідка |
| **Шифрувальне коло** | Крути коло, доки шифровка не стане словами |
| **Прокрадися** | Покроково обходь вартових із ліхтарями, ховайся в кущах |

У джури три серця. Помилка коштує серце, але двері можна пройти знову. Одного разу Сизокрил приносить паляницю й повертає серце. На деяких дверях є 🔀 бічний шлях: важче, зате більше зірок. Виконане доручення дає зірки, покращує показники держави й відкриває 🔓 таємний варіант відповіді в розмові свого акту. Усі доручення зібрані у вкладці «Доручення».

Зірки підвищують **звання**: Джура → Козак → Хорунжий → Сотник → Полковник → Отаман Долі → Лицар Залізного хреста → Легенда Соборності. Ще є 25 **медалей**. Усе зібране видно у вкладці «Торба».

Керування з клавіатури: пробіл показує весь текст одразу, клавіші 1–4 обирають відповідь. У грі «Влуч у зону» тисни пробіл.

## Візуальний стиль

Гра повністю піксельна: шрифт Pixelify Sans з кирилицею, власний набір піксельних іконок, власні спрайти міні-ігор, емодзі, перетворені на спрайти, 9-зрізні рамки, об'ємні кнопки, сегментовані смужки й ступінчаста анімація. Дев'ять сцен актів 1919–1921 років (зимовий шлях, степ із тачанками, Холодний Яр, Севастополь, Сиваш, бронепотяг, Камʼянець, Замостя, поле памʼяті) намальовано піксель за пікселем скриптом `scripts/scenes/scenes.py`. Детальний опис правил, палітри й анімацій лежить у [docs/VISUAL_STYLE.md](docs/VISUAL_STYLE.md).

## Для вчителів і батьків

- Акти відкриваються по черзі. Наступний стане доступним, лише коли гравець пройде попередній. До вже пройдених актів можна повертатися через мапу актів на титульному екрані або хроніку над сценою.
- Перемикач 💡 у верхній панелі ховає підказки про наслідки, щоб дитина думала самостійно.
- Прогрес зберігається в браузері. Старі збереження першої версії автоматично переносяться.

## Вхід лише за запрошенням

Гра — окремий сайт, але відкривається тільки за запрошенням з основного сайту Historic_up (репозиторій `ValentiTeach/NMT_TEST`). Викладач створює посилання в адмін-панелі → «Гра».

Як це працює:
1. Посилання має вигляд `https://<гра>/i/<токен>`. Токен — дані запрошення, зашифровані AES-256-GCM. Ключ є лише на основному сайті.
2. `GET /i/<токен>` показує сторінку з кнопкою «Увійти в гру» і нічого не витрачає. Тому одноразове посилання не згорає, коли месенджер будує прев'ю.
3. `POST /i/<токен>`: файл `middleware.ts` на Vercel питає основний сайт із секретом `GAME_REDEEM_SECRET`, чи чинне запрошення. Якщо так, видає підписану cookie-сесію (`HttpOnly`, `Secure`) і перенаправляє на `/`.
4. Будь-який інший шлях, включно з `/assets/*`, без чинної сесії показує «Вхід лише за запрошенням». Жоден файл гри не віддається.
5. `/logout` забуває вхід на пристрої.

Змінні оточення проєкту гри на Vercel:

| Змінна | Значення |
| --- | --- |
| `MAIN_SITE_URL` | адреса основного сайту |
| `GAME_REDEEM_SECRET` | спільний секрет із сайтом (`openssl rand -hex 32`) |
| `GAME_SESSION_SECRET` | ключ підпису cookie, лише тут (`openssl rand -hex 32`) |
| `GAME_SESSION_VERSION` | необов'язково. Змінити, щоб вивести всіх із гри |

Без цих змінних ворота зачинені. Локально (`bun run dev`) middleware не працює, і гра відкривається без запрошення. Логіка воріт — `server/gate.ts`, тести — `server/gate.test.ts`. Повна схема й модель загроз — `docs/GAME_INVITES.md` у репозиторії сайту.

```bash
bun install
```

```bash
bun run dev
```

```bash

```


Перемалювати піксельні сцени (потрібен Python 3 і Pillow):

```bash
python3 scripts/scenes/scenes.py
```

Структура:

- `src/game/chapters.ts` — порядок актів (єдине джерело правди).
- `src/game/historicalData.ts` — фракції, постаті, акти 1917–1919 та діалоги.
- `src/game/story1919_1921.ts` — акти 1919–1921: діалоги, питання, підказки, щоденник, вікторини, постаті, хронологія.
- `src/game/dialogueExtras.ts` — компромісні й таємні варіанти, питання до персонажів перших актів.
- `src/game/missions.ts`, `src/game/missions1919_1921.ts` — доручення, міні-ігри привалів, рівні «Прокрадися» й мапи «Маршруту», знахідки нових сцен.
- `src/game/minigameLogic.ts` — чиста логіка нових ігор (шифр, брід, прокрадання, маршрут, кораблі) з розвʼязувачами для тестів.
- `src/game/sprites.ts`, `src/components/PixelSprite.tsx` — піксельні спрайти міні-ігор.
- `src/game/lore.ts` — голуб Сизокрил, знахідки, щоденник, вікторини, міні-ігри, медалі.
- `src/game/rules.ts` — стан гри, звання, медалі, міграція збережень, бої та фінали.
- `src/components/` — екрани гри, `MissionRunner.tsx` — коридор дверей, `ArcadeView.tsx` — Ігротека, `minigames/` — шістнадцять міні-ігор.
- `scripts/scenes/` — генератор піксельних сцен.
- `server/gate.ts`, `middleware.ts` — ворота «вхід лише за запрошенням».
- `src/game/content.test.ts` — перевіряє, що в сюжеті немає битих посилань, кожен акт має щоденник, вікторину, міні-гру й доручення, рівні «Прокрадися» та мапи «Маршруту» розвʼязні, кораблі можна заповнити, а брід завжди існує.
- `src/game/rules.test.ts` — правила, міграція старих збережень, історичний фінал для «канонічного» проходження.
